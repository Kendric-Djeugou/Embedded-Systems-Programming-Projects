## 🚀 Featured Project: Dual Functional Embedded Gadget

A multi-mode embedded system integrating a **Spirit Level** and a **Countdown Timer**, controlled via a state machine.

### 🔹 Key Features
- Finite State Machine (FSM) for mode control  
- Accelerometer-based tilt detection with averaging  
- Real-time countdown timer with user input  
- LCD, LED bank, and 7-segment display integration  
- Button-controlled interaction with debounce handling  
- Buzzer feedback system  

### 🔁 Modes
- **Title Page** → System introduction  
- **Spirit Level** → Tilt detection and visual feedback  
- **Timer** → User-defined countdown with display outputs
